## clone, domain, workspace

$ desolate clone acme/widgets
  read key: registered
  write key: registered (it asks you before every push)
cloned acme/widgets: 1 branch(es), default main, 1 LFS object(s); pushable.
next: desolate domain create <slug> && desolate domain <slug> add --repo acme/widgets

[exit 0]

$ desolate domain create a
created the domain a ("a").
next: desolate domain a add --repo <owner>/<repo>
[exit 0]

$ desolate domain a add --repo acme/widgets
acme/widgets is now in the domain a: every workspace in it gets a checkout, borrowing the mirror's objects.
next: desolate up a
[exit 0]
